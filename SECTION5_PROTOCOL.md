## Protocol text (effective)

5.0 Scope: detection quality and cross-asset association only; no trading claims. H1 (primary): feature detectors beat returns-only baselines per family on BOTH (a) hit rate versus alarm rate on stable-day splices, metric = partial area under the curve of hit rate against null alarm rate for alarm rates 0-0.5, divided by 0.5 (A6 item 2; replaces the median-delay formulation), and (b) out-of-sample QLIKE for next-60-min SPY volatility; intersection-union test per family, Holm across the THREE H1 families Gaussian HMM, Student-t HMM, HSMM (A6 item 4, A9 item 1). BOCPD is secondary: scored and reported, outside H1 and its Holm family. H1(c), secondary (A8 item 5): detection within 60 min of each FOMC statement's actual release time (stated on its federalreserve.gov statement page or press-conference page, or the documented schedule 14:15 before April 2011 and 14:00 from 2013, Lucca and Moench 2015; meetings with no source are excluded; A11 item 3, A12 item 2) in uncontaminated test segments, at the frozen alarm frequency, features versus baseline; paired exact sign test, Wilson intervals, outside Holm. H2 (primary): around confirmed calm-to-stressed SPY breaks, TLT/HYG/gold/USD cumulative return from T to T+30 lies outside a placebo distribution matched on time-of-day slot, era and SPY volatility decile (10,000 draws); horizons -30 and +5/15/30/60 min; stressed-to-calm is secondary. S1: return between T_d and T_c versus equal-length placebo. S2: H2 verdict agreement and response correlation across detectors. E1: footprint taxonomy (cite Cieslak & Pang). E2: overnight gaps versus early-session breaks. D1: feature-family selection frequency, including same-family co-selection. Multiple testing: Holm primary, BH secondary, exploratory uncorrected. Features: 4.3.9 matrix v2 by name and hash. Changes: dated, hashed amendments only.

5.1 Folds: 30 LEGACY and 4 RAW TRAIN-only folds (A4); inner train / validation / test with 5-session embargoes (validation and test each lose their first 5 sessions). Inner train fits all parameters, scaling, winsorization 0.5/99.5, Amihud normalization, Lee-Mykland Student-t threshold. Seasonal and relative-volume baselines are already causal. Intraday horizons only.

5.2 Pools: primary 19 (both eras); sensitivity 80 (RAW only; matrix v2 keeps 83 columns, 5.2 drops the three jump_variation__sadj columns, 83 - 3 = 80; A6 item 6c). Enforced exclusions: overnight, raw_volume, log_raw_volume, raw_volume__sadj, response assets, cross-era rows; jump_variation__sadj dropped; Lee-Mykland flag sensitivity-only. Log only if strictly positive in inner train. Every feature model = deseasonalized 5-min return + 1 to 6 selected features; baselines = the deseasonalized 5-min return only, same architecture and hyperparameter budget.

5.3 Decision bars every 5 min (stamped minute 4, 9, ... after 09:30); alarm time = t+1 min. The 5-minute grid is primary; the 1-minute grid (390 updates) and the 15-minute grid are sensitivity analyses on the final setups only. Baseline return input = the 5-minute return divided by the median |5-minute return| of the same grid slot over the previous 20 sessions (>= 10 finite; NaN = skipped update; past sessions only); every model uses this deseasonalized return (A6 item 5). Start at the first grid bar with all features present; abstain before. Session reset (HMM initial probabilities; HSMM state plus duration=1; BOCPD run length 0). No alarms on the first 2 updates. Any missing feature means a skipped update: HMM transition-only; HSMM duration advances with hazard; BOCPD hazard-only, statistics unchanged; no alarms on skips. Last decision: last grid bar with availability at or before the close. Report abstention and skip shares.

5.4 Gaussian HMM diagonal, K 2-4, EM 3 starts, 200 iterations, tol 1e-6 per observation (an EM run converges when the change of the total training log-likelihood divided by the number of real training updates is below 1e-6; cap 500 iterations; the same for every model; cap hits are reported per family; A12 finding 6 as amended by A13 item 1), variance floor 1e-6. Student-t HMM via EM with hidden scales, df in [2.1, 30], restart if a state is under 1% occupancy. HSMM K 2-3, free-form durations by EM, durations in elapsed grid intervals capped at the session's scheduled updates, cut off at session end. BOCPD Normal-Gamma per feature (mu0 0, kappa0 1, alpha0 1, beta0 1 on standardized inputs), lambda 12/39/78, run length truncated at 200. Seeds and versions recorded. HSMM constants (A14, A14.1; as in the code, unchanged): the duration hazard update is h[k, d] = (leave + 0.5 h0) / (leave + stay + 0.5) with the pooled hazard h0, last bin 1, clipped to [1e-6, 1]; duration cap Dmax = 78 bins of one grid interval (the 78 decision updates of a full session); +1e-12 on initial-state and transition counts; +1e-12 guard on state-weight denominators. Student-t HMM (A14, A14.2): per start the number of attempts and whether the kept fit has every state at 1% or more are recorded; the kept fit is the highest-likelihood start among those satisfying the 1% rule, and if none does after 10 attempts the highest-likelihood fit is kept and flagged; flagged fits are counted in every report.

5.5 Events. HMM and HSMM (A6 item 1, A7 item 1): old state = argmax at updates 1-2 and at each alarm (not re-based inside the refractory period; A12 finding 7); alarm (= confirmed event, T_c) when log(s) - log(P(old state)) > theta for 3 consecutive real updates, s = the probability mass outside the old state summed from the other states, theta real on the log-odds scale (thr = 1/(1 + exp(-theta))); T_d = the first of the three; a skipped update resets the count to 0; the first 2 updates are silent; 30-min refractory after an alarm. BOCPD: alarm when the most likely run length falls by at least m updates (m real, >= 1) and then holds 3 updates (`detect_bocpd_map`). Unconfirmed by the close: dropped and counted (a candidate run still open at the close; A12 finding 15). States ordered by return variance within each fit. All timestamps at availability time. Direction rule at T_c: SPY 1-min realized variance over [T_d, T_c] versus the 60 min before T_d; above 1 = calm-to-stressed.

5.6 Synthetic splices and thresholds. Splices per fold from the fold's TEST sessions for H1(a) (A6 item 2): stable days only; variance ratios 1.5, 2, 3, 5, 10 (variance ratios), both directions, permanent and 30/60/120-min sandwiches, 24 splices per cell, 400 null splices of two distinct stable days of the same volatility tercile, tau on the 11:05-14:30 grid (grid slots 94-299) for permanent breaks and null splices, and for sandwiches availability <= 14:00 with the first bar after the sandwich inside the session (slot <= 269 for 30 and 60 minutes, <= 264 for 120 minutes) (A12 finding 9); session A's history for baselines, features recomputed, prices rescaled for continuity. Splice scale (A8 item 1): the post-tau variance of B is expressed in session A's baseline units, so the labelled ratio equals the ratio the detector sees; one factor f per splice applied to every price field of B after tau, volume unchanged. Stable day (A6 item 6b): 390 bars with >= 98% finite closes; deseasonalized 1-min variance = r^2 / median r^2 of the same slot over the previous 20 sessions (>= 10 finite); mean over the last 195 bars / first 195 bars in [0.8, 1.25]; no hourly block mean above 2 times the median block mean. A fold with fewer than 8 stable test days skips H1(a), recorded, without error (A6 item 2, A8 item 3). Curve: for every threshold of the sweep, x = confirmed alarms per null session, y = share of break splices with a confirmed alarm within 60 min after tau whose first run update (T_d; BOCPD: the drop update) is available strictly after tau (A12 finding 14); y(x) = the highest y reached at alarm rate <= x; metric = partial area for x in [0, 0.5] divided by 0.5; power by variance ratio reported as the partial area and the hit rate at x = 0.1. The sweep is uniform over theta in [0, 30] step 0.25 and m in [1, 80] step 1 (A7 item 3). This is a sensitivity measure under simulated conditions on real stable days, not real-world detection accuracy. Section 6 event thresholds (A6 item 3, A7 item 2): calibrated on the REAL validation sessions of each fold by bisection so that the detector gives 0.2 confirmed alarms per session (strict end returned; bounds theta [0, 30], m [1, 80]; flags when the strictest bound is above target or the loosest is below it); the realized test-session frequency is reported. BOCPD threshold rule for non-monotone alarms (A6 item 6a): among sweep values with calibration-null false-alarm share <= 0.10, the highest calibration hit rate, ties to the smaller index; else the strictest value, flagged INFEASIBLE. QLIKE: regime-conditional forecast of next-60-min variance, decision bars at or before 15:00 (12:00 on early closes); Diebold-Mariano test. Historical anchors (Flash Crash 2010-05-06 14:42, 2018-02-05) are descriptive; COVID only in evaluation. Hindsight segmentation is secondary.

5.7 No screening beyond Section 4; the pilot drops only zero-variance features. Open item N.3 (selection on all of TRAIN) is a disclosure with the justification of A8 item 4; no in-fold recomputation.

5.8 Per fold, own validation only; the test segment never informs selection. Greedy forward from the return-only model, fixed K=3 / lambda=39, 1 start; stop when the relative QLIKE gain is under 1% or at 6 features; then tune K/lambda with 3 starts. Objective: validation QLIKE; tie-breaks: fewer features, then synthetic delay, then dictionary order. In the implementation the synthetic delay is not computed during the search (A10 item 1), so it does not break ties. Budget exhausted: keep the best so far, record it. All folds if the budget allows, else every 2nd (by amendment). Final setup for 5.13: feature count = median across folds rounded half up (A9 item 3), filled by selection frequency, ties by dictionary order; K/lambda = mode, ties to the smaller value.

5.9 H1 scored per fold on that fold's own selected setup, on its test segment: (a) pAUC(features) - pAUC(baseline), (b) mean QLIKE(baseline) - mean QLIKE(features) with the Diebold-Mariano statistic per fold; paired block bootstrap over consecutive folds (block 3; centred, one-sided, add-one correction) is the primary p-value of each component (A9 item 3), plus Wilcoxon, plus sign consistency, reported beside it. Per family the intersection-union p-value is the larger of the two component p-values. Cross-family comparison is descriptive.

5.10 Robustness: by era; Student-t HMM sensitivity excluding folds whose kept feature or baseline fit is flagged (A14.2); LEGACY +5/+10 min delay; 3 seeds; 1/15-min grids; RAW sensitivity set; threshold +/-0.05.

5.11 Holm: H1 across the three H1 families (BOCPD excluded); H2 across 4 assets. BH for secondary. Power: simulated minimum detectable effects.

5.12 Freeze final setups, thresholds (era-level, 5.13) and hashes before any evaluation output exists (hashed freeze document, never overwritten, refused once evaluation output exists). The H2 primary detector = the family passing H1 with the lowest median VALIDATION QLIKE; ties go to the simpler model, order Gaussian HMM < Student-t HMM < HSMM (A9 item 2); BOCPD cannot be the H2 primary detector.

5.13 Era-level threshold (A11 item 1): for each era with n TRAIN sessions, each family's frozen final setup is refitted on sessions 0 to n - 64, the next 5 sessions are the embargo, and the last 58 sessions are native calibration sessions on which the A7 rule (bisection to 0.2 alarms per session, same bounds and flags) sets the threshold; the threshold is frozen in 5.12 and used unchanged with the refit below (it comes from a model fitted on a shorter sample than the model it is applied to; the realized rate on the calibration sessions is reported). Refit the frozen setup on full TRAIN per era; run once on the exposed evaluation periods; no retuning (guarded runner: freeze hash verified, token equal to the freeze hash, one run per era). Fold tests are development evidence; 5.13 is confirmatory.
