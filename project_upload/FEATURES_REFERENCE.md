# FEATURES_REFERENCE

Read-only reference for the paper's features section. Written 2026-11-11 from the repository at code version `a0323ed24d68e896`; nothing was run, refitted or edited to produce it. Every number below is read from the file cited beside it.

## 0. Conventions that apply to every feature

- **Data.** SPY 1-minute bars of the Section 3.10 canonical panel, one era at a time (LEGACY = PiTrading rows of the HF Clean file, RAW = HF Raw IEX). TRAIN sessions only (split manifest `frozen_documents/section430_executable_split_manifest.csv`): LEGACY 2003-01-02..2018-12-21 (4,022), RAW 2022-03-07..2024-12-23 (705). Loader: `section431_step3_verification/prototype_sources/section4_3_1_candidates.py:56-98`; TRAIN check `section5/s5_lib.py:99-106`.
- **Notation.** Bar t = the minute stamped at its start (slot 0 = 09:30). C, H, L, V = close, high, low, volume of the bar; r_t = ln(C_t / C_{t-1}). A bar is observed when its row exists and passes the Section 3.4 OHLCV validity rule.
- **Causal timing (policy P1, `section431_step3_all_in_one_results/policy_4_3_1_P1_20261030T233123Z.json`; R2 as amended by note N4 D1).** A bar stamped t is usable at t + 1 minute (`available = t + 1 min`, asserted at `section431_step3_verification/prototype_sources/section4_3_1_candidates.py:70`). Every feature at bar t uses bars <= t only. Rolling windows reset at the session open (a window of W returns ends at slot t >= W and never crosses sessions). Only two elements cross sessions, both from previous sessions of the same era only: the relative-volume baseline and the `__sadj` baseline. No LEGACY/RAW crossing (R3); no overnight return (R4). Prefix-invariance and isolation tests: `section431_step3_all_in_one_results/a4_prefix_isolation_report.json` (PASS both eras).
- **Window semantics.** "W returns" = r_{t-W+1}..r_t; "W+1 closes" = C_{t-W}..C_t. Strict = all W returns eligible; partial90 = at least ceil(0.9 W) eligible, sum rescaled by W/n.
- **Seasonal adjustment (`__sadj`, amendment A4 F2).** x__sadj_t = x_t / b_t, with b_t the median of x at the same minute slot over the previous 20 sessions of the era, needing >= 10 finite values and b_t > 0, else NaN. Code: `step11_a4_rerun_4_3_4_7_8.py:44-59 (WINDOW = 20, MIN_COUNT = 10 at :29)`; called from `section5/s5_lib.py:136-147`. Brute-force check: 105,000 cells per era, 0 mismatches (`section431_step3_all_in_one_results/a4_sec4_3_4_7_8_report.json`).
- **What reaches the model (Section 5).**
  - Decision bars every 5 minutes, slots 4, 9, ..., read at availability t + 1 min (`section5/s5_lib.py:18-19, 220-241`).
  - Every model also receives the 5-minute return, ln(C_t / C_{t-5}) (slot 4 from the session open), divided by the median |5-min return| of the same grid slot over the previous 20 sessions (>= 10 finite) (`section5/s5_lib.py:224-233`; `section5/s5_fast.py:71-92`; protocol 5.3). This is not a pool column; it is always in, and it is the whole input of the baseline model.
  - Preprocessing fitted on each fold's inner train only (`section5/s5_lib.py:176-207`): zero-variance drop; Amihud columns divided by their inner-train median (note N3); log if strictly positive in inner train (never for return, momentum, close location); winsorise at the 0.5 / 99.5 percentiles (`:21`); z-score. Out of sample, a non-positive value of a logged column becomes NaN.
  - **Model-level missing-data rule (protocol 5.3; `section5/s5_lib.py:244-250`).** A sequence starts at the first grid bar with every selected feature present (abstain before). Afterwards any NaN feature makes the bar a skipped update: HMM transition only, HSMM duration advances, BOCPD hazard only; no alarm on a skipped bar. No imputation anywhere.
- **Pool definitions.** `pools()` reads the frozen matrix `section431_step3_all_in_one_results/a4_sec4_3_9_frozen_matrix_v2.csv` (`section5/s5_lib.py:57-62`): primary = 19 columns kept in both eras; sensitivity = 83 kept on RAW minus the three `jump_variation_W__sadj` = 80. **A20 rule 1** (`AMENDMENT_A20.md` rule 1; `section5/s5_lib.py:65-77`): scale-type stems rv, downside, abs_return, intrabar_range enter only as `__sadj`. Primary 19 -> **13**; sensitivity 80 -> **69** (asserted at `section5/s5_a22.py:397-398`; AMENDMENT_A22 rule 3f). Enforced exclusions (`section5/s5_lib.py:25-26, 80-96`): overnight_return_open, raw_volume, log_raw_volume, raw_volume__sadj, response assets; Lee-Mykland columns sensitivity-only.
- Window, warm-up, minimum valid observations and TRAIN coverage are copied from the frozen matrix v2. Coverage = share of all TRAIN grid rows with a finite value (Step 6 numerator rule).

### 3c. Exposure note

- **Pre-rebuild stages used evaluation-period data.** 4.4 and 4.8A load RAW through 2026 (4.4: 1,145 RAW full sessions; 4.8A: RAW 1,155 and LEGACY 4,829 sessions, `section4_8_feature_selection_stage1_results/summary.json`), and 4.5 uses a March 2025 placebo. They are descriptive or inner-validation screens and chose no feature. But they were known when A3 (the 4.3.4-4.3.9 rules) and N1 were written (`SECTION4_COMPLETE.md`, deviation 18 and limitation 12). The frozen protocol therefore records `NO_UNEXPOSED_PERIOD_IDENTIFIED` and prior feature and model selection exposure for 2025-2026 (`frozen_documents/protocol_20261029T032641Z.json`); both evaluation periods are retrospective.
- **The rebuilt screening (4.3.4-4.3.9) used TRAIN rows only.** But it used all of TRAIN, outside the folds (audit #3; disclosed, protocol 5.7, A8 item 4). Each fold's test segment therefore informed which columns are in the pool, though not which are selected (5.8 uses the fold's validation only). The 4.3.1 builder also constructed features on LEGACY 2018-12-24..2022-03-04 and the RAW embargo days for coverage summaries; no feature matrix was built for 2025 onward (`SECTION4_COMPLETE.md`, limitation 37).
- **Contamination by later work** (protocol 5.14): 8 of 34 folds are excluded from confirmatory H1 (marked * in section 2).
